日本の外務省が当時写し取った、黄興宛ての暗号電報2通（1916年5月20日付）を、変換式から読み通した記録です。
- 資料：外務省記録「特定人ノ発受郵便物取調」第3巻、JACAR B03050089100、コマ0076〜0078（ローマ字の暗号文）、コマ0079〜0081（当時の日本側の作業紙）
- 方式：漢字を中国の標準電碼（4桁）にし、それを仮名3字に置き換え、ローマ字で送る「三仮名コード」
- 変換式：友清理士氏（Cryptiana）が特定したもの

- **第1電**：軍務院の撫軍10名から黄興へ。
  - 平文は1916年の刊本『護國軍紀事』第5期にあり、先行リポジトリが特定済み。**初めての解読ではなく、刊本との照合です。**
  - 最終の表は、刊本の107字のうち102字と一致します（[docs/VERIFICATION.md](docs/VERIFICATION.md)）。
- **第2電**：肇慶にいた6名（林虎・李根源・程子楷・文羣・楊永泰・章士釗と推定）から黄興へ。
  - 刊本は見つかっていません。この表は、変換式から独立に読んだ結果です。
  - 署名は、黄興の返電（JACAR B03050731500）の暗号文から出る宛先「隱印崧詔鬯行」と照らして比定しました。
- 推定に頼る箇所、確度「中」の修正、先行リポジトリの留保は、[docs/OPEN.md](docs/OPEN.md) にまとめました。

## この解読で加えたこと
**先行研究の成果（この解読の前提）**
- 三仮名コードの変換式と、作業紙からの部分的な読み：友清理士氏
- 第1電の平文（刊本の特定）：先行リポジトリ saberwatchmanga/sun-circle-cipher-1916

**この解読で加えたこと**
1. **第2電の通読**
   - 先行リポジトリは、第2電の多くの組を空欄のまま残していました（0274、watuno、kutena、tathe、caose、6381、akuso など）。
   - この解読では、それらに 僅・恐・發・卿・兵・贑・代・謀・舊部・楷・粤・出 という読みを付け、全文を文として通しました。
   - 推定や確度「中」の箇所は、`data/corrections.csv` と [docs/OPEN.md](docs/OPEN.md) に、根拠とともに載せています。
2. **差出人6人の比定**
   - 黄興の返電（B03050731500）の暗号文を変換式で戻し、宛先「隱印崧詔鬯行」を、手書きの写しに頼らずに確かめました。『近代史資料』総50号の活字と一致します。
   - 日本側の手書きの訳「隱印崧蕘邕行」（Bourdeau 氏のリポジトリ dbourdeau/cyphersolver の targets/sunyatsen/HUANG_NOTES.md による）は、写し誤りとみられます。
   - 字・号との対応から、差出人を林虎・李根源・程子楷・文羣・楊永泰・章士釗と比定しました。6人の字・号（隱青・印泉・崧生・詔雲・暢卿・行嚴）は、1916年の『軍務院考實』の職員錄でも確かめました（楊永泰の字は、職員錄では宛先の「鬯」と同じ音の「暢卿」）。
   - 『近代史資料』の注は、4・5番目を曾其衡・趙正平としています。しかし、趙正平の字は「厚生」で（1916年の職員錄でも同じ）、宛先の「鬯」と合わず、曾其衡の「衡」は署名の仮名と合いません。
3. **第2電に書かれている内容**：1916年5月20日時点の、差出人側の説明や予定です。事実として確かめたものではありません。
   - 軍務院は名ばかりで、委員・代表の会議はまだ組織されていない。
   - 李烈鈞の協和軍は、10日以内にそろい、韶州を経て江西へ入る（李烈鈞の軍は、実際に6月19日に韶州で戦っている）。
   - 林虎は第四師長となり、旧部隊約1万を集めて江西へ出る（電文は「虎任第四師長，收集舊部約萬，亦卽出贑」）。
     - 「師」と「舊部」は、綴りを直して読んだ字で、確度は「中」。
     - 「第四師長」という肩書きは、後の記録と合わない。『軍務院考實』の職員錄では、林虎は護國第六軍の總司令で、李烈鈞の軍の第四師長は方聲濤（[docs/OPEN.md](docs/OPEN.md)）。
   - 章士釗は、日本へ行って近況を伝える。
   - 冒頭の「潤輔」が誰かは、確定していない。職員錄には、日本駐在の委員として張孝準（字は潤農）がいて、文脈は合うが、仮名は合わない（[docs/OPEN.md](docs/OPEN.md)）。
4. **暗号文の第二の写し**
   - JACAR B03050731100 に、肇慶の太田領事が1916年5月21日に外務省へ送った、同じ電文の写しがありました。表書きに、2通の要旨が書かれています。
   - これで、日付（5月20日）と、第2電の差出人に李根源が入っていることが、当時の日本側の記録で確かめられました。
   - 2つの写しを比べると、この解読で直した5語の綴り（短・適・唐・光・情・羣の箇所）が、第二の写しにそのまま書かれていました（[docs/VERIFICATION.md](docs/VERIFICATION.md)）。
5. **細かい点**
   - 変換式で表せる電碼は9199までで、200の倍数の電碼の扱いは、実際の電文では確かめられないこと。
   - 作業紙（コマ0080）の書き込みが「韶」ではなく「詔」であること。
   - 転写を、別の AI による答えを見せない転写3回と照合したこと（[docs/VERIFICATION.md](docs/VERIFICATION.md)）。

## 使い方
Python 3 の標準ライブラリだけで動きます（`fix.py`・`beam.py` を除く）。

```
python3 src/build_groups.py                      # data/groups.csv と outputs/romaji_corrected.txt を作る
python3 src/check.py outputs/romaji_corrected.txt
python3 -m unittest discover -s tests
```

`fix.py`・`beam.py` は、候補を並べるための頻度モデルを使います。材料の取得方法は `src/lm.py` の冒頭に書きました。材料はリポジトリに含めていません。

## AI の使用
- この解読の作業の大部分は、Anthropic の AI である Claude（Claude Code）が行いました。
  - 画像からのローマ字の書き起こし
  - 変換器の作成
  - 修正候補の探索
  - 史料との照合
  - 文書の作成
- 公開者は、方針の指示と確認を行いました。
- **転写の作り方**：ローマ字原文（`data/romaji_raw.txt`）は、Claude が JACAR の画像を拡大して1字ずつ読んだものです。公開者は1字ずつの確認はしていません。代わりに、次の2つと照らしました。
  - 別の AI（OpenAI の Codex）に、答えを見せずに3回転写させた結果
  - 先行リポジトリの転写

  食い違った箇所は画像で見直し、5語を直しました（[docs/VERIFICATION.md](docs/VERIFICATION.md)）。この比較は直すのに使ったので、独立の数字とはしていません。直した後に、Codex にもう1回、新しい文脈で答えを見せずに読ませ（独立の2回目）、字の一致率は 94.6% でした（[docs/METHOD.md](docs/METHOD.md)）。
- 作業の一部は、Claude Code の /goal 機能で、目標に達するまで自動で続けさせました。
- **使ったモデル**
  - Claude：Claude Opus 5.5（`claude-opus-5-5`）。作業の途中で使った補助のエージェント3つも、同じモデル。
  - 転写の照合：OpenAI の Codex（`codex-cli 0.163.0-alpha.10.2`、モデル `gpt-6.1-sol`）。
  - 独立の2回目の書き起こし：同じ Codex CLI、既定のモデル（実行記録にモデル名は出ない）。
- AI の読みや判断には、誤りがありえます。修正の根拠と確度は `data/corrections.csv` と `docs/OPEN.md` に書きました。原資料（JACAR の画像）で確かめてください。
