### 「新しい」と書ける範囲（この確かめの結果から）
- 第2電：「初めて読んだ」とは書けない。1916年の作業紙で字の多くが既に読まれ、2026年には友清氏と saberwatchmanga がそれを公表している。新しいと言えるのは、(1) 先行で未解決・空欄だった組や、変換式で出る字が文に合わなかった組に読みを付けたこと、(2) それらをつないで全文を文として通したこと、(3) 同じ暗号文の第二の写し（JACAR B03050731100）を見つけて照らしたこと（調べた先では、第二の写しへの言及は見当たらない）。
- 差出人：「6人を初めて比定した」とは書けない。返電の宛先として4人は刊本の注にあり、6人の一覧も saberwatchmanga に仮説としてある。新しいと言えるのは、返電の暗号文と1916年の職員錄による確かめと、4・5番目の比定を文羣・楊永泰とした根拠。
- README の「先行リポジトリは、第2電の多くの組を空欄のまま残していました」は、上の数字（未解決10組。ほかに、変換式で出る字だけが置かれ、文に合わない組がある）が分かるように書くのがよい。また、1916年の作業紙に第2電の字が83字あることを、先行との関係に書くのがよい。

## 数字の出どころ
- 83字（確定）：友清氏のページの、作業紙 p.3〜p.5 の転記の87組から、第1電の結び（光・公・望・哿）の4組を除いた数。中には作業紙の誤り（齎/齋、葛＝萬、俣＝俟）も含む。
- 未解決10組（確定）：saberwatchmanga の data/whole_source_alignment.tsv（2026-10-10 の版）で、第2電の範囲（114行）のうち status が UNRESOLVED の行。nashi・maseso・notaekona・tesu・tathe・caose・watuno・kutena・yunikeiso・satef。
- 組ごとの比べ（計算）：この解読の第2電121組と、上の表の114行を、電碼の並びで自動で対応づけると96組が対になった（残る25組は対にならず、比べていない）。96組のうち、作業紙・鉛筆の書き込みとして表に載る字と同じものが70組、表のいずれかの列（変換式で出した字を含む）と同じものが84組だった。
