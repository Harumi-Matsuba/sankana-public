# 解読の記録

**日本語** ｜ [English](DECIPHERMENT.en.md)

## 資料
- 外務省記録「各国内政関係雑纂／支那ノ部／革命党関係（亡命者ヲ含ム）／特定人ノ発受郵便物取調」第3巻（JACAR B03050089100）
  - コマ0076〜0078：ローマ字の暗号文（用紙5枚、126語）
  - コマ0079〜0081：当時の日本側の作業紙（暗号文をカタカナに書き直し、一部に漢字を書き込んだもの）
- 画像はリポジトリに含めていない。コマ番号で参照する。

- 同じ電文の第二の写しが、JACAR B03050731100（肇慶の太田領事の電報 第四二號、大正5年5月21日発）の画像24〜26ページにある。表書きに2通の要旨がある。照合の結果は [VERIFICATION.md](VERIFICATION.md) の第3節。

## 方式：三仮名コード
漢字1字を中国の標準電碼（4桁の数字）にし、それを仮名3字に置き換え、さらにローマ字で送る方式。
電碼から仮名3字への変換式は、友清理士氏（Cryptiana）が特定した（[SOURCES.md](../SOURCES.md)）。

```
1字目 = S1[c // 200]            S1 = アカサタナハマヤラワイキシチニヒミリヰウクスツヌフムユルエケセテネヘメレヱオコソトノホモヨロ
2字目 = S2[(c - 1) % 10]        S2 = アイウエオカキクケコ
3字目 = S3[((c - 1) // 10) % 20] S3 = ホヘフヒハノネヌニナトテツチタソセスシサ
```

この解読は、この式を逆に使った（`src/kana.py`）。
- ローマ字を仮名に分け、3字ずつ組にする。
- 組を電碼に戻し、Unicode Unihan の kTaiwanTelegraph で漢字にする。

この式から、強い制約が出る。
- 2字目は「ア〜オ・カ〜コ」に限られる。
- 3字目は「サ行・タ行・ナ行・ハ行」の20字に限られる。

崩れた箇所を見つけて直すのに、この制約を使った。

## 手順
1. **ローマ字原文の書き起こし**（`data/romaji_raw.txt`）
   - 画像から字どおりに写した。修正は入れていない。
   - ローマ字では、エとヱ、イとヰが区別できない。
2. **崩れた語の読み直し**（`data/corrections.csv`）
   - 規則に合わない組や、意味の通らない組について、語の綴りを画像で見直した。
   - よくある取り違えは次のとおり。
     - 筆記体の h/k、wa/ha、n/u、a/o、m/n、ss/sh
     - エ/ヱ
   - 126語のうち40語を直した。それぞれの理由・確度・根拠を、`corrections.csv` に1行ずつ書いた。
3. **原文から読めない組**
   - 第1電の5組は、刊本の字で補った。
   - 第2電の4組は、文脈と黄興の返電から推定した。
4. **表の作成**：`python3 src/build_groups.py` で、全229組の表 `data/groups.csv` を作る。

## 結果
### 第1電（組0〜107）
軍務院の撫軍10名から黄興へ。日本到着を歓迎し、今後の指導を頼む内容。

> 黃克強先生鑒奉删電知公抵日歡躍逾恆堯等碌碌庸才勉起討賊正慮綆短適逢公歸願承不遺俯賜提挈公首倡共和富有方略各國情勢考查復殷將來內政外交諸賴指導大局所繫惟公圖之唐繼堯岑春煊梁啓超劉顯世陸榮廷龍濟光呂公望蔡鍔李烈鈞陳炳焜哿

- この電報の平文は、1916年の刊本『護國軍紀事』第5期に「軍政府歡迎黃克強電」として載っている。刊本は先行リポジトリが特定した。
- **この電報は、初めて解読したものではない。刊本との照合として扱う。** 照合の結果は [VERIFICATION.md](VERIFICATION.md)。
- 富・有・方・各・復の5字は、原文の綴りからは読めず、刊本の字で補った。

### 第2電（組108〜228）
肇慶にいた6名（林虎・李根源・程子楷・文羣・楊永泰・章士釗と推定）から黄興へ。李根源が差出人に入っていることは、太田領事の電報の表書き（「李根源等ヨリ黄興ニ宛テタルモノ」）でも確かめられる。

> 公抵日喜甚潤輔當告公近形以定進行方略軍務院僅擁虛名委員代表等會皆未組織協和軍旬內可齊卽由韶入贑非俟幹卿協和兵入湘贑吾人恐難發言馮段調停此間暫置代理參謀事源專任之虎任第四師長收集舊部約萬亦卽出贑楷調粤中湘軍卽出湘釗擬來東面達近情虎源楷羣泰釗哿（オワリ）

- この電報の平文が載った刊本は、見つかっていない。先行リポジトリにも、第2電の論点や仮説がある。この表は、それとは別に、変換式から独立に読んだ結果。
- 内容（要約）
  - 軍務院は名ばかりで、委員・代表の会議はまだ組織されていない。
  - 協和軍（李烈鈞。協和は字）は10日以内にそろい、韶州を経て江西へ入る。
  - 林虎は第四師長として旧部隊約1万を集めて江西へ出る。
  - 章士釗は日本へ行って近況を伝える。
- 推定に頼る組は4組ある。
  - 164 贑
  - 211 出
  - 223 楷
  - 225 泰

  修正の確度を「中」とした組もある。どちらも、検討は [OPEN.md](OPEN.md) に書いた。

### 署名と黄興の返電
黄興の返電（1916年5月25日、JACAR B03050731500）も、同じ三仮名コードで送られている。
- 暗号文（ローマ字は友清氏のページによる）を変換式で戻すと、冒頭は「隱印崧詔鬯行諸兄鑒正寄函」になる。
- 『近代史資料』総50号 p.123「致肇慶軍務院電」の冒頭（隱、印、崧、詔、鬯、行諸兄鑒）と一致する。この照合は `tests/test_formula.py` で再現できる。
- 宛先の6字を字（あざな）・号として読むと、第2電の署名6字と次のように対応する。

| 返電の宛先 | 人物（字・号） | 第2電の署名 | 署名の組の状態 |
|---|---|---|---|
| 隱 | 林虎（字は隱青） | 虎 | 変換式どおり |
| 印 | 李根源（字は印泉） | 源 | 修正読み |
| 崧 | 程子楷（字は崧生） | 楷 | 推定（原文ヌクヘ。ニクヘ＝楷と1字目だけ違う） |
| 詔 | 文羣（号は詔雲） | 羣 | 修正読み（原文 nukufu を mukufu と読む） |
| 鬯 | 楊永泰（字は鬯卿） | 泰 | 推定（原文ヌアタ。ヒアタ＝泰と1字目だけ違う） |
| 行 | 章士釗（字は行嚴） | 釗 | 変換式どおり |

字・号は Wikipedia による。6人とも、1916年の『軍務院考實』の職員錄でも確かめた。
- 第1卷：林虎（隱青）・李根源（印泉）・章士釗（行嚴）・程子楷（崧生）（PDF の250・254・259ページ）
- 第2卷（附録『兩廣都司令部考實』）：文羣（詔雲）・楊永泰（暢卿）（PDF の230・236・237ページ）。楊永泰の字は、職員錄では「暢卿」と書かれ、宛先の「鬯」とは同じ音の別の字。返電の宛先が、第2電の署名者と同じ人とは限らない。この点は [OPEN.md](OPEN.md) で扱う。
