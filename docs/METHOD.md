# 方法・数字・AI の使用・限界

**日本語** ｜ [English](METHOD.en.md)

詳しい手順は [DECIPHERMENT.md](DECIPHERMENT.md)、照合の細部は [VERIFICATION.md](VERIFICATION.md) にある。この文書は、それらの要点と数字をまとめたもの。

## 1. 方法
1. **書き起こし（1回目）**：Claude が JACAR B03050089100 コマ0076〜0078 の画像を拡大して、ローマ字を1字ずつ読んだ（`data/romaji_raw.txt`、126語・1,265字）。
2. **変換**：友清理士氏の変換式（ローマ字 → 仮名3字 → 電碼4桁 → 漢字）で戻した（`src/kana.py`）。電碼 → 漢字は Unicode Unihan の kTaiwanTelegraph。
3. **修正**：規則に合わない組や文の通らない組は、語の綴りの崩れとみて、候補を並べて直した（`data/corrections.csv`。語40件・組9件。理由・確度・根拠つき）。
4. **照合**：刊本（第1電）、暗号文の第二の写し、黄興の返電、当時の日本側の作業紙と照らした。

## 2. 数字
| 項目 | 結果 | 根拠 |
|---|---|---|
| 2回目の書き起こし（別のモデルが、1回目を見せずに読んだもの） | OpenAI Codex（gpt-6.1-sol）を3回。`data/romaji_raw.txt` との字の一致率は 94.0%・94.3%・94.2%（違う字 76・72・74 / 1,265） | `second/`、`src/second.py` |
| 同・語ごと | 126語のうち、Codex 3回が同じ 60、2回が同じ 55、ばらばら 11。多数の読みがある115語のうち、`romaji_raw.txt` と同じ 78、違う 37 | 同上 |
| 対照（平文との照合） | 第1電の最終の表は、刊本の107字のうち102字と一致 | [VERIFICATION.md](VERIFICATION.md) 第1節 |
| 較正（答えに頼らない部分だけ） | 修正を入れていない「変換式どおり」の組は、59組中54組が刊本と一致。残る5組は、刊本との文の違い（慮/憂、提挈公/教言、查/察） | 同上 |
| 対照（第二の写し） | 2つの写しで、126語のうち114語の綴りが同じ。直した40語のうち5語は、修正後の綴りが第二の写しにそのまま書かれていた | [VERIFICATION.md](VERIFICATION.md) 第3節 |
| 対照（返電） | 黄興の返電の暗号文（友清氏のローマ字）を同じ式で戻すと、全46組が読め、宛先「隱印崧詔鬯行」が『近代史資料』の活字と一致 | [VERIFICATION.md](VERIFICATION.md) 第4節、`tests/` |

- **2回目の書き起こしの扱い**：Codex の多数の読みが1回目と違った42語（照合した時点）は、すべて画像で見直した。5語は1回目の読み違いと判断して直し、残る37語は、Codex の読みを当てると組がずれる・規則外になる・刊本と合わなくなるなどの理由で、1回目の読みを残した（[VERIFICATION.md](VERIFICATION.md) 第2節）。上の一致率は、直した後の `romaji_raw.txt` で数えたもの。
- **較正の注意**：第1電の「修正読み」43組は、刊本を見られる状態で直したものを含む。そのため、修正読みが刊本と合うことは較正に数えていない。第2電には刊本がなく、較正はない。
- 鍵のかき混ぜ（1000回）の対照はしていない。この方式は公開された変換式で決まり、鍵を推定していないため。代わりに、平文（刊本）・第二の写し・返電との照合を対照とした。

## 3. AI の使用
- Claude（Anthropic、Claude Opus 5.5 `claude-opus-5-5`）：画像からの書き起こし、変換器の作成、修正候補の探索、史料との照合、文書の作成。作業の途中で同じモデルの補助エージェントを3つ使った。作業の一部は Claude Code の /goal 機能で、目標に達するまで自動で続けさせた。
- OpenAI Codex（`codex-cli 0.163.0-alpha.10.2`、モデル `gpt-6.1-sol`）：2回目の書き起こし3回。画像だけを渡し、ファイルの読み込みやコマンドの実行がなかったことを実行記録（`second/codex_run*_events.jsonl`）で確かめた。依頼文は `second/codex_prompt.txt`。
- 公開者（人）：方針の指示と、結果の確認。**ローマ字の書き起こしを、人が1字ずつ確かめたことはない。**

## 4. 限界
- AI どうしの書き起こしの一致は、人による確認の代わりにならない。Codex の転写は先行リポジトリの転写の土台にもなっており、Codex と先行リポジトリの一致は独立の裏付けではない。
- 第2電は刊本がなく、変換式から独立に読んだもの。推定4組と、確度「中」の修正を含む（[OPEN.md](OPEN.md)）。
- 刊本との照合には、先行リポジトリの手作業の翻字を使った。刊本の画像を読み直してはいない。
- 第二の写し（`data/romaji_copy2.txt`）の書き起こしも Claude によるもので、2回目の書き起こしはしていない。
