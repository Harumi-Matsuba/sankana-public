## corrections.csv の列
| 列 | 意味 |
|---|---|
| 段階 | 「語」は語の綴りの修正、「組」は組の補い・推定 |
| 語番号または組番号 | 語の番号（0から）、または組の番号（0から） |
| 元の綴り | 語の行は原文の綴り、組の行は観測された仮名 |
| 修正後 | 語の行は修正後の綴り、組の行は採った字 |
| 理由・確度・根拠 | 修正の理由、確度（高・中・刊本）、根拠 |
| reason_en・certainty_en・grounds_en | 上の3列の英訳 |

## groups.csv の列
| 列 | 意味 |
|---|---|
| 組 | 組の番号（0〜228）。0〜107が第1電、108〜228が第2電 |

## English

| File | Contents |
|---|---|
| `romaji_raw.txt` | Literal transcription of the romaji cipher text of frames 0076–0078 (no corrections). One line = 3 words |
| `romaji_copy2.txt` | Transcription of a second copy of the same cipher text (JACAR B03050731100, images 24–26). ° is a small o written above the line |
| `corrections.csv` | List of corrections (40 words, 9 groups) |
| `groups.csv` | Table of all 229 groups, generated by `src/build_groups.py` |
| `worksheet.csv` | Japanese analysts' worksheet notes (frames 0079–0081) compared with this decipherment (26 items) |
| `ctc_kTaiwanTelegraph.tsv` | Telegraph code → character table, extracted from Unicode Unihan |

The column names are in Japanese because the programs and tests read them. Their meanings:

### corrections.csv
| Column | Meaning |
|---|---|
| 段階 | 語 = correction of a word's spelling; 組 = a group filled or inferred |
| 語番号または組番号 | word number (from 0) or group number (from 0) |
| 元の綴り | for words, the original spelling; for groups, the observed kana |
| 修正後 | for words, the corrected spelling; for groups, the character adopted |
| 理由・確度・根拠 | reason, certainty (高 high / 中 medium / 刊本 from the print) and grounds, in Japanese |
| reason_en・certainty_en・grounds_en | English translations of those three columns |

### groups.csv
| Column | Meaning |
|---|---|
| 組 | group number (0–228); 0–107 are Telegram 1, 108–228 Telegram 2 |
| 仮名 | the three kana of the group |
| 電碼 | standard telegraph code (4 digits); blank for filled or inferred groups |
| 字 | character |
| 区分 | category: 変換式どおり = read by the formula as written; 修正読み = read after correcting a word's spelling; 刊本で補う = filled from the print; 推定 = inferred; 終わりの印 = end marker (オワリ) |
| 語番号 | number(s) of the word(s) the group's kana come from |

### worksheet.csv
| Column | Meaning |
|---|---|
| コマ・組 | worksheet frame and corresponding group number |
| この解読の字 | character adopted in this decipherment |
| 日本側の書き込み（判読） | the note on the worksheet (my reading) |
| 一致・メモ | agree (一致) / disagree (不一致), and a memo |
| note_reading_en・agreement_en・memo_en | English translations of those three columns |
